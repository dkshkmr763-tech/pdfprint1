FREE WEBSITE - ONLY HTML / CSS / JAVASCRIPT (no PHP, no database, no server)
==========================================================================
Files go DIRECTLY from the customer's phone to your shop PC (WebRTC). The website only shows the
upload page; it never receives or stores any file.

STEP 1  Upload these files to ANY free static host (your EdgeOne Pages site works!):
          index.html   send.html   config.js   vendor/peerjs.min.js
        (keep the folder "vendor"). Other free hosts: Netlify (drag & drop folder), Cloudflare Pages,
        GitHub Pages, Vercel.
STEP 2  Open  https://YOUR-SITE/send.html  in a browser. It should show "Send your files" and
        "This QR code is not valid" (normal - the real QR adds a code after #).
STEP 3  On the shop PC open QR Print Studio -> click "Any network" -> type your site address
          https://YOUR-SITE      (no /send.html)
        -> Save. The QR now looks like  https://YOUR-SITE/send.html#...
        The shop PC program must stay OPEN while the customer sends.
STEP 4  Customer scans the QR with ANY phone on ANY network, picks files, taps Send.

NOTES
 - The shop PC needs internet. The phone needs internet. They do NOT need the same Wi-Fi.
 - Uses free public helpers: PeerJS signaling (0.peerjs.com) and Google/Cloudflare STUN.
   Rarely, a strict mobile network blocks direct connections ("Could not connect"). Then add a TURN
   server in config.js (both copies: the site and the program's) or use Wi-Fi.
 - Each file is limited only by the phone's memory (tested 6 MB).
